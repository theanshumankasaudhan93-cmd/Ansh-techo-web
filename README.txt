Ansh Cyberweb Technologies Pvt. Ltd. - Website
==============================================
Open index.html in any browser. No build step, no dependencies.

Before going live, replace these placeholders:
1. WhatsApp number: search "910000000000" in index.html (country code + number, no +). 3 places.
2. Phone: "+91 00000 00000" and tel: link in the footer.
3. Email: hello@anshcyberweb.com (footer).
4. Office address: footer.
5. Map: replace the .map placeholder block with your Google Maps iframe embed code.

Customise:
- Prices / plans: "pricing" section in index.html.
- Brand colours: --bg, --gold at the top of styles.css.
- Slogans: the "lines" array in script.js and the marquee strip in index.html.
- Fonts: Plus Jakarta Sans via Google Fonts (falls back to system fonts offline).
Animations stop automatically for visitors who enable "reduce motion".
